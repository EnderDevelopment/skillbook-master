# SkillBookMaster

SkillBookMaster is a Minecraft plugin that provides players with skill books, allowing them to learn and apply various skills in-game. This plugin is designed to enhance player progression and engagement by offering unique abilities and features through skill books.

## Install

1. Download the SkillBookMaster plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file into the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Ensure the plugin is installed and enabled on your Minecraft server.
2. Players can obtain a skill book by using the command `/skillbook`.
3. Open the skill book to read its contents and learn about the available skills.
4. Apply the skills to enhance your in-game abilities.
